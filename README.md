# 🎬 Netflix Movies Data Analysis

## 📌 Project Overview

This project analyzes a Netflix movies dataset to uncover trends, patterns, and insights that can help support business decisions. Using Python and data analysis libraries, the dataset is cleaned, explored, and visualized to answer important questions about movie genres, popularity, production trends, and voting statistics.

The project demonstrates the complete data analysis workflow, including data preprocessing, exploratory data analysis (EDA), visualization, and interpretation of results.

---

## 🎯 Objectives

The notebook answers the following business questions:

- What is the most frequent movie genre on Netflix?
- Which genre has the highest average popularity?
- Which movies have the highest popularity and what are their genres?
- How has movie production changed over the years?
- Which movie has the highest vote average?
- Which movie has the highest vote count?

## 📊 Project Workflow

### 1. Data Loading
- Import required libraries
- Load the dataset using Pandas

### 2. Data Cleaning
- Check dataset information
- Identify duplicate records
- Convert numerical columns to appropriate data types
- Convert release dates into datetime format
- Handle missing or invalid values

### 3. Exploratory Data Analysis (EDA)
- Analyze genre distribution
- Study popularity trends
- Find top-rated movies
- Examine vote counts and vote averages
- Analyze movie releases over time

### 4. Data Visualization
Visualizations are created to better understand:

- Genre frequency
- Popularity distribution
- Highest-rated movies
- Movie production trends
- Voting statistics

